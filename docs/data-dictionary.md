# Data Dictionary: BookMySlot

This document details all database tables, columns, data types, constraints, and relational mappings managed by Entity Framework Core in the SQLite database (`bookmyslot.db`).

---

| Column Name | Data Type | Nullable | Key / Constraint | Description |
| :--- | :--- | :---: | :---: | :--- |
| `Id` | `TEXT` | No | PK | GUID Primary Key generated by Identity |
| `FullName` | `TEXT (100)` | No | - | Full legal or display name of the user |
| `Email` | `TEXT (256)` | Yes | Index | User email address |
| `NormalizedEmail` | `TEXT (256)` | Yes | Unique Index | Uppercase normalized email for lookups |
| `UserName` | `TEXT (256)` | Yes | - | Username (matches email in this project) |
| `NormalizedUserName`| `TEXT (256)` | Yes | Unique Index | Uppercase normalized username |
| `PasswordHash` | `TEXT` | Yes | - | PBKDF2 with HMAC-SHA256 password hash |
| `SecurityStamp` | `TEXT` | Yes | - | Random value updated upon password change |
| `ConcurrencyStamp` | `TEXT` | Yes | - | Optimistic concurrency token |
| `EmailConfirmed` | `INTEGER` | No | Default `0` | Boolean flag (1=True, 0=False) |
| `CreatedAtUtc` | `TEXT` | No | Default UtcNow | Registration timestamp in UTC |

## 7. Table: `SlotReservations`
Hardware-enforced concurrency lock table preventing double-booking.

| Column Name | Data Type | Nullable | Key / Constraint | Description |
| :--- | :--- | :---: | :---: | :--- |
| `AppointmentSlotId`| `INTEGER` | No | **PK**, FK | Primary Key and Foreign Key to `AppointmentSlots.Id` |
| `AppointmentId` | `INTEGER` | No | **Unique FK** | Unique Foreign Key to `Appointments.Id` |
| `ReservedAtUtc` | `TEXT` | No | - | Timestamp when the lock was established |

*Concurrency Rule:*
- `AppointmentSlotId` as **Primary Key** ensures no two rows can ever exist for the same slot.
- Cancellation removes the row, freeing the slot.
- Completed and NoShow appointments retain their reservation row for audit integrity.
