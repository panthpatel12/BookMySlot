================================================================================
BookMySlot — Appointment Booking System
SYSTEM REQUIREMENTS & DEPENDENCY SPECIFICATION
================================================================================

1. SYSTEM & OPERATING SYSTEM REQUIREMENTS:
--------------------------------------------------------------------------------
- Operating System: Windows 10/11, macOS (12+), or Linux (Ubuntu 20.04+, Debian, Fedora)
- Architecture: x64 or ARM64
- Memory (RAM): Minimum 4 GB (8 GB recommended)
- Disk Space: 500 MB free disk space for runtime and packages
- Browser: Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari

2. RUNTIME & SDK REQUIREMENTS:
--------------------------------------------------------------------------------
- .NET SDK: Version 10.0 (or .NET 8.0+)
- Download URL: https://dotnet.microsoft.com/download
- Verification command:
    dotnet --version

3. DATABASE SPECIFICATION (ZERO CONFIGURATION):
--------------------------------------------------------------------------------
- Database Engine: SQLite (File-based: bookmyslot.db)
- External Database Server: NOT REQUIRED (SQLite is fully embedded)
- Note: SQLite is built into the application via EF Core. You do NOT need
  to install MySQL, SQL Server, or Docker on the target PC! The database file
  and all tables are created automatically on the first run.

4. NUGET PACKAGES (Automatically restored via dotnet restore):
--------------------------------------------------------------------------------
Project: src/BookMySlot/BookMySlot.csproj
  - Microsoft.EntityFrameworkCore.Sqlite (v10.0.13)

--------------------------------------------------------------------------------
Windows:
    Double-click "run.bat"

    cd src\BookMySlot
    dotnet run --urls "http://localhost:5100"

Mac / Linux:
    cd src/BookMySlot
